# Plan 03-01: Cloud Transcriber Contracts, Groq & OpenAI HTTP Clients & Error Mapping

**Phase**: 03 - Cloud Engine  
**Wave**: 1  
**Requirements**: STT-05, STT-06, APP-05, APP-06  

## Objective
Implement cloud STT transcription clients for Groq (`whisper-large-v3-turbo`) and OpenAI (`whisper-1` / `gpt-4o-transcribe`), with multipart WAV upload, Portuguese (`pt`) language parameter, prompt/vocabulary bias, strict API key masking, and granular error classification (`no_network`, `invalid_api_key`, `rate_limit`, `timeout`).

## Requirements Covered
- **STT-05**: User can choose a cloud engine (Groq whisper-large-v3-turbo or OpenAI gpt-4o-transcribe) by entering an API key; cloud is opt-in only.
- **STT-06**: Cloud failures (no network, invalid key, rate limit, timeout) classify with explicit codes, prevent silent fallback, and preserve the recording for retry.
- **APP-05**: User-facing error notices in pt-BR.
- **APP-06**: Strict key masking in memory, headers and log events.

## Architecture & Design
1. **Core Domain Contracts (`Somning.Core.Cloud`)**:
   - `CloudProvider`: enum or string constants: `None = "none"`, `Groq = "groq"`, `OpenAi = "openai"`.
   - `CloudEngineConfig(CloudProvider Provider, string ApiKey, string? CustomVocabulary = null, string? CustomEndpoint = null)`.
   - `CloudTranscriptionException`:
     - Subtypes / ErrorCodes:
       - `no_network`: Network unreachable, DNS failure, connection refused.
       - `invalid_api_key`: HTTP 401 Unauthorized.
       - `rate_limit`: HTTP 429 Too Many Requests.
       - `timeout`: Request timed out or cancellation token triggered.
       - `bad_request`: HTTP 400 with API error details.
   - `ICloudTranscriptionClient`:
     - `Task<CloudTranscriptionResult> TranscribeAsync(string wavPath, CloudEngineConfig config, CancellationToken ct)`.
     - `CloudTranscriptionResult(string Text, long DurationMs, long InferMs, string Model)`.
2. **Implementation (`Somning.Core.Cloud.CloudTranscriptionClient`)**:
   - Implements `ICloudTranscriptionClient` using `HttpClient`.
   - Endpoint routing:
     - Groq: default `https://api.groq.com/openai/v1/audio/transcriptions`, model `whisper-large-v3-turbo`.
     - OpenAI: default `https://api.openai.com/v1/audio/transcriptions`, model `whisper-1`.
   - Payload:
     - `MultipartFormDataContent` with:
       - `file`: stream of WAV audio.
       - `model`: selected model name.
       - `language`: `"pt"`.
       - `response_format`: `"json"`.
       - `prompt`: optional custom vocabulary string if present.
   - Headers:
     - `Authorization: Bearer <ApiKey>` (never logged, redacted in ToString/diagnostics).
   - Error Handling:
     - HTTP 401 -> throws `CloudTranscriptionException("invalid_api_key", ...)`
     - HTTP 429 -> throws `CloudTranscriptionException("rate_limit", ...)`
     - HTTP 408 / Timeout -> throws `CloudTranscriptionException("timeout", ...)`
     - SocketException / HttpRequestException -> throws `CloudTranscriptionException("no_network", ...)`
3. **Key Masking & Security**:
   - `ApiKeyMasker.Mask(string? key)`: keeps first 3 and last 3 characters if length > 8, masks rest as `***` (e.g. `gsk_***abc`). If key is shorter, masks entire key as `***`.
   - Never exposes plaintext API key in exception messages or log fields.
4. **Overlay Notices Update (`Somning.Core.Overlay`)**:
   - Extend `OverlayNoticeKind` with:
     - `CloudNoNetwork` -> `"Sem conexão com a internet"`
     - `CloudInvalidKey` -> `"Chave de API inválida"`
     - `CloudRateLimit` -> `"Limite de requisições excedido"`
     - `CloudTimeout` -> `"Tempo limite esgotado"`
