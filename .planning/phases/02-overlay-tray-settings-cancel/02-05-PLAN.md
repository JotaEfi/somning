# Plan 02-05: Settings Dialog & Dynamic Audio Device Switching

**Phase**: 02 - Overlay, Tray, Settings & Cancel  
**Wave**: 5  
**Requirements**: APP-01, AUD-02, OUT-04, OVL-04  

## Objective
Implement the user-facing Settings dialog in pt-BR opened from the system tray menu ("Configurações..."). It allows configuring hotkey, selecting the active microphone from available devices (applied dynamically to the next capture without restarting the app - AUD-02), toggling auto-paste vs clipboard-only (OUT-04), toggling sound cues (OVL-04), vocabulary prompt, and cloud API key (DPAPI-protected).

## Requirements Covered
- **APP-01**: "Configurações..." menu item in tray opens the settings window.
- **AUD-02**: Microphone selection applied without application restart:
  - Enumerates WASAPI capture devices via NAudio.
  - When the user selects a device, the active audio factory updates the device ID/index dynamically for subsequent captures.
- **OUT-04**: Auto-paste off setting:
  - When AutoPaste is false, `EffectRunner` outputs text to clipboard only (`CopyOnly`) without injecting `Ctrl+V`.
- **OVL-04**: Sound cues toggle / audio feedback on capture start/stop.
- Persisted via `ISettingsStore` / `JsonSettingsStore` (from Plan 02-01) with DPAPI encrypted secrets.

## Tasks & Responsibilities

### Task 1: Core Settings Integration & Dynamic Audio Device Provider (OpenCode)
- `AudioDeviceEnumerator` in `Somning.Platform.Windows.Audio`:
  - Lists available WASAPI recording endpoints with friendly names and IDs.
- `DynamicAudioSourceFactory` in `Somning.Platform.Windows.Audio`:
  - Wraps audio source creation with a mutable/configurable device ID or device name.
  - Calling `SetDevice(string? deviceId)` updates the device used on the next capture without app restart (AUD-02).
- Update `UserSettings` / `EffectRunner` to respect `AutoPaste` toggle:
  - If `AutoPaste == false`, trigger `CopyOnly` effect instead of `Deliver` (OUT-04).
- Unit tests in `Somning.Core.Tests`.

### Task 2: Win32/STA Native Settings Dialog (Antigravity & OpenCode)
- `SettingsWindowManager` or native Win32 dialog in `Somning.Platform.Windows.Settings`:
  - Opened via Tray menu callback `OnOpenSettings`.
  - Single instance dialog (if already open, brings existing to foreground).
  - pt-BR localized UI elements:
    - Microfone: ComboBox with available devices.
    - Atalho: Hotkey selector + conflict validator warning label (HOTK-05).
    - Opções: Checkbox "Colar automaticamente no aplicativo ativo" (OUT-04), Checkbox "Emitir sons de início/fim" (OVL-04).
    - Vocabulário / Prompt: TextBox para termos específicos.
    - Provedor de Transcrição: Local (Whisper) / Nuvem (Groq / OpenAI) + Campo de Chave API (oculta, protegida com DPAPI).
    - Botões: "Salvar" (persiste via `ISettingsStore` e aplica), "Cancelar".

### Task 3: App Composition Wiring & Integration Tests
- Wire `TrayIconManager.OpenSettingsRequested` to `SettingsWindowManager.Show()`.
- Integration tests in `Somning.Integration.Tests/Settings`:
  - Test dynamic microphone change without restart (AUD-02).
  - Test AutoPaste toggle producing `CopyOnly` vs `Deliver` (OUT-04).
  - Test settings round-trip from dialog save.
