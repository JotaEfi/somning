# Plan 02-02: Esc Cancellation & Hotkey Reconfiguration

**Phase**: 02 - Overlay, Tray, Settings & Cancel
**Wave**: 2
**Requirements**: HOTK-04, HOTK-05

## Objective
Enable instant cancellation of an in-progress dictation when the user presses `Esc` (recording discarded, no transcription, no paste, sidecar marked cancelled) and support configurable hotkey bindings with collision warning for common Windows shortcuts.

## Context & Architecture
- Requirement HOTK-04: "User can press Esc while recording to cancel — nothing is transcribed or pasted".
- Requirement HOTK-05: "User can change the hotkey in settings and gets a warning if it conflicts with a known shortcut (e.g. Ctrl+Shift layout toggle)".
- When `Esc` is pressed during an active recording, the reducer must emit `DiscardCapture(Id)` (or cancel effect), update the sidecar to terminal stage with outcome `cancelled`, and skip queueing for transcription.
- The `KeyboardHook` detects `VK_ESCAPE` when recording is active and suppresses or handles it as a cancellation trigger without leaking.

## Tasks

### Task 1: Reducer Cancellation Support (HOTK-04)
- Add `CancelRequested(long NowMs)` event to `DictationEvent`.
- Add `DiscardCapture(string Id)` effect to `DictationEffect`.
- In `DictationReducer`:
  - When `CancelRequested` arrives while `Capture` is active:
    - Mark recording sidecar as `RecordingStage.Terminal`, outcome `"cancelled"`, reason `"user_cancel_esc"`.
    - Set capture slot to stopping/cancelled.
    - Do NOT add recording to `Pending` queue for transcription.
    - Emit `DiscardCapture(Id)` and `UpdateSidecar`.
  - When `CaptureStopped` arrives for a cancelled recording, clean up without transcribing or pasting.
- Pure unit tests in `Somning.Core.Tests/Dictation/DictationReducerCancelTests.cs`:
  - `CancelRequested_WhileRecording_EmitsDiscardCaptureAndTerminalSidecar`
  - `CancelRequested_WhenIdle_IsNoOp`
  - `CaptureStopped_AfterCancel_DoesNotEnqueueTranscription`

### Task 2: Hotkey Conflict Validator (HOTK-05)
- Implement `HotkeyConflictValidator` in `Somning.Core.Settings`:
  - Validates `HotkeyBinding` against known Windows system combinations:
    - `Ctrl + Shift` alone (Windows input language toggle `WM_INPUTLANGCHANGEREQUEST`)
    - `Alt + Shift` (keyboard layout switch)
    - `Win + Space` (input language selector)
    - `Alt + Tab`, `Ctrl + Alt + Del`, `Win + L`, `Win + D`
  - Returns `HotkeyConflictResult` (`IsConflicting`, `WarningMessage`, `Severity`: Warning/Blocked).
- Unit tests in `Somning.Core.Tests/Settings/HotkeyConflictValidatorTests.cs`.

### Task 3: Hook & Effect Runner Integration
- Update `KeyboardHook`:
  - Checks if recording is active (`IsRecordingActive`).
  - If `VK_ESCAPE` down occurs while recording is active, fires cancellation callback.
- Update `EffectRunner`:
  - Handles `DiscardCapture`: cancels active `SpoolWriter`, deletes or cleans up active spool WAV, closes mic stream cleanly.
- Integration tests in `Somning.Integration.Tests/Dictation/CancelDictationTests.cs`.
