# Plan 02-03: System Tray Menu & Last Transcript Repaste

**Phase**: 02 - Overlay, Tray, Settings & Cancel
**Wave**: 3
**Requirements**: APP-01, OUT-05, APP-05

## Objective
Implement the persistent system tray icon with a localized pt-BR context menu (Configurações, Colar último, Abrir logs, Sair), wire the re-paste of the last transcript into the focused window, and enable quick log folder inspection and clean shutdown.

## Context & Architecture
- Requirement APP-01: "App runs in the system tray with a menu: Configurações, Colar último, Abrir logs, Sair".
- Requirement OUT-05: "User can re-paste/copy the last transcript from the tray".
- Requirement APP-05: "All user-facing text is in pt-BR; language is stored as a config value for future expansion".
- The system tray icon must be hosted on an STA message loop (`TrayIconManager`) using Win32 `Shell_NotifyIconW` and native context menu (`CreatePopupMenu`, `InsertMenuItemW`, `TrackPopupMenuEx`).
- "Colar último" must be enabled only when at least one transcript has completed in this session; clicking it places the text on clipboard and injects Ctrl+V to the active target.
- "Abrir logs" opens `SomningPaths.LogsDir` in Windows File Explorer.
- "Sair" initiates graceful application shutdown.

## Tasks

### Task 1: Last Transcript Tracker & Repaster
- Add `ITranscriptHistory` / `LastTranscriptTracker` in `Somning.Core.Output` or `Somning.App.Dictation`:
  - Remembers the last delivered or transcribed text.
  - Exposes `string? LastTranscript { get; }` and `bool HasTranscript => !string.IsNullOrEmpty(LastTranscript);`.
- Implement `RepasteLastTranscriptAsync(ITextOutput output)` to deliver the last transcript to the active target and copy to clipboard.
- Unit tests in `Somning.Core.Tests`.

### Task 2: Win32 Native Tray Icon & Menu (APP-01, APP-05)
- Implement `TrayIconManager` in `Somning.Platform.Windows.Tray`:
  - Registers notify icon via `Shell_NotifyIconW` (`NIM_ADD`, `NIM_MODIFY`, `NIM_DELETE`).
  - Listens for `WM_RBUTTONUP` / `WM_LBUTTONUP` / `WM_CONTEXTMENU`.
  - Builds native popup menu with pt-BR labels:
    - "Configurações..."
    - "Colar último" (disabled/grayed out if no last transcript exists)
    - "Abrir pasta de logs"
    - "-" (separator)
    - "Sair"
  - Fires callbacks: `OnOpenSettings`, `OnRepasteLast`, `OnOpenLogs`, `OnExitRequested`.
- Exposes `UpdateTooltip(string tooltip)`.

### Task 3: App Wiring & Integration Tests
- Wire `TrayIconManager` into `AppComposition`:
  - Subscribes to `Host.Notified` for `outcome` with text to update `LastTranscript`.
  - Maps `OnRepasteLast` to trigger paste of the remembered text into the current foreground.
  - Maps `OnOpenLogs` to open `SomningPaths.LogsDir`.
  - Maps `OnExitRequested` to signal shutdown.
- Integration test in `Somning.Integration.Tests/Tray/TrayIconManagerTests.cs` and `Somning.Integration.Tests/Output/RepasteLastTranscriptTests.cs`.
