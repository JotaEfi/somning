# Plan 04-03: Per-User Installer, Directory Layout & Soak/Paste Matrix Verification

**Phase**: 04 - Packaging, Autostart & Hardening  
**Wave**: 3  
**Requirements**: DIST-01, DIST-03  

## Objective
Create a per-user installer and deployment layout for Somning that runs unattended on a clean Windows 10 machine without developer tools, installs to `%LOCALAPPDATA%\Somning\app\`, sets up desktop/start menu shortcuts, and validates production readiness via a paste-matrix report.

## Requirements Covered
- **DIST-01**: User can install Somning via a per-user Windows installer that works on a clean Windows 10 machine without dev tools.
- **DIST-03**: Paste-matrix report (Notepad, terminal, elevated window notices) and soak validation.

## Architecture & Packaging
1. **Packaging Script (`tools/package.ps1`)**:
   - Publishes `Somning.App` and `Somning.Engine` as `win-x64` self-contained binaries (`dotnet publish -c Release -r win-x64 --self-contained`).
   - Bundles Whisper/Vulkan runtime dependencies into the application directory structure.
   - Generates a standalone installer script `install.ps1` (or compiled self-extracting installer) that installs Somning into `%LOCALAPPDATA%\Somning\app\` per-user.
2. **Directory Layout**:
   - `%LOCALAPPDATA%\Somning\app\Somning.App.exe`
   - `%LOCALAPPDATA%\Somning\app\engine\Somning.Engine.exe`
   - `%LOCALAPPDATA%\Somning\models\`
   - `%LOCALAPPDATA%\Somning\recordings\`
   - `%LOCALAPPDATA%\Somning\logs\`
3. **Shortcuts & Start Menu**:
   - Creates a Start Menu shortcut in `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Somning.lnk`.
4. **Uninstaller**:
   - Creates `uninstall.ps1` that unregisters the autostart HKCU Run key, removes shortcuts, and cleanly removes the application directory while preserving user recordings/logs.
5. **Paste Matrix Report (`tools/verify-matrix.ps1`)**:
   - Automated report validating safe paste and clipboard-only fallback across different targets (standard edit control, rich edit, elevated window UIPI detection).

## Tasks
- **Task 1**: Packaging automation and installer generation.
- **Task 2**: Clean profile unattended installation verification and paste matrix report.

## Verification
- Unattended install runs successfully on paths with spaces/non-ASCII.
- Installed binary launches and runs headless/tray correctly.
- Matrix report generated and committed.
