# Plan 02-01: Single Instance Mutex & Settings Core with DPAPI

**Phase**: 02 - Overlay, Tray, Settings & Cancel
**Wave**: 1
**Requirements**: APP-02, APP-03, APP-05, OUT-04, HOTK-05, STT-07, OVL-04

## Objective
Establish the application lifecycle safety net (single instance mutex so duplicate Somning instances exit immediately) and the complete immutable settings domain model in `Somning.Core` with atomic JSON persistence, corrupt-file self-healing, and Windows DPAPI encryption for sensitive secrets (API keys).

## Context & Architecture
- Somning runs in the system tray and must strictly prohibit multiple background instances contending for the global `WH_KEYBOARD_LL` hook, microphone, and Vulkan engine.
- Configuration must be persisted to `%APPDATA%\Somning\settings.json` (or customizable test directory).
- If the settings file is partially written or corrupted (e.g. sudden power loss or process termination), the store must archive the corrupted file as `settings.json.corrupt.<timestamp>` and seamlessly return safe default settings.
- Sensitive values (such as Cloud API keys) must never be stored in plain text; they must use Windows Data Protection API (DPAPI) scoped to `DataProtectionScope.CurrentUser`.
- All user-facing defaults are set for Portuguese (`pt-BR`).

## Tasks

### Task 1: Single Instance Mutex
- Implement `SingleInstanceMutex` in `Somning.Platform.Windows` / `Somning.App`.
- Named mutex: `Local\Somning_SingleInstance_App_Mutex`.
- Returns a disposable handle if acquired; if already owned, signals non-ownership so `Program.cs` exits cleanly with code 0.
- Unit/integration tests asserting second acquisition fails while first is held.

### Task 2: UserSettings Domain Model & DPAPI Secret Protection
- Define `UserSettings` record in `Somning.Core.Settings`:
  - `HotkeyBinding Hotkey` (Modifiers: Ctrl+Shift, Key: Space)
  - `string? MicrophoneDeviceId` (null = Default)
  - `string EngineBackend` ("vulkan" or "cpu", default "vulkan")
  - `string CloudProvider` ("none", "groq", "openai", default "none")
  - `string? EncryptedApiKey` (base64 DPAPI blob, null by default)
  - `bool AutoPaste` (default true; when false, text remains on clipboard without Ctrl+V)
  - `bool PlaySoundCues` (default false)
  - `string CustomVocabulary` (default empty string)
  - `int TapThresholdMs` (default 300)
  - `string Language` (default "pt-BR")
- Implement `ISettingsProtector` and `DpapiSettingsProtector`:
  - `string Protect(string secret)`
  - `string Unprotect(string encrypted)`

### Task 3: Atomic JsonSettingsStore with Corrupt-File Recovery
- Implement `ISettingsStore` and `JsonSettingsStore`:
  - Path: `%APPDATA%\Somning\settings.json` (injectable base directory for testing).
  - Atomic write via `.tmp` write + `File.Move(..., overwrite: true)`.
  - Corrupt file handling: if `JsonException` occurs during load, rename to `.corrupt.<timestamp>` and return default `UserSettings`.
- Unit tests in `Somning.Core.Tests`:
  - `UserSettings_DefaultValues_MatchPhase2Requirements`
  - `SettingsStore_RoundTrip_PreservesAllFields`
  - `SettingsStore_CorruptJson_RecoversToDefaultAndArchivesCorruptFile`
  - `DpapiSettingsProtector_RoundTrip_EncryptsAndDecryptsSuccessfully`
  - `SingleInstanceMutex_SecondInstance_FailsToAcquire`
