# Plan 04-01: Start-with-Windows Autostart, Registry HKCU & Tray/Settings Toggle

**Phase**: 04 - Packaging, Autostart & Hardening  
**Wave**: 1  
**Requirements**: DIST-02, APP-01, APP-02, APP-05  

## Objective
Implement start-with-Windows functionality via the per-user `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` registry key, add the `--tray` startup argument so the app starts minimized to the system tray on logon, and expose the "Iniciar com o Windows" toggle in the Settings dialog and tray menu.

## Requirements Covered
- **DIST-02**: User can enable start-with-Windows (starts minimized to tray).
- **APP-01**: App runs in the system tray with a menu: Configurações, Colar último, Abrir logs, Sair.
- **APP-02**: Settings persist across restarts.
- **APP-05**: All user-facing text is in pt-BR ("Iniciar com o Windows").

## Architecture & Design
1. **Core Settings & Abstraction (`Somning.Core.Settings`)**:
   - `UserSettings`: add `public bool StartWithWindows { get; init; } = false;`.
   - `IAutostartManager`:
     - `bool IsEnabled();`
     - `void SetEnabled(bool enabled, string? executablePath = null, string arguments = "--tray");`
2. **Platform Implementation (`Somning.Platform.Windows.Autostart.RegistryAutostartManager`)**:
   - Manages `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` key with value name `"Somning"`.
   - On `SetEnabled(true)`: writes `$"\"{executablePath}\" {arguments}"`.
   - On `SetEnabled(false)`: deletes value if present.
   - Non-elevated: runs in user context without requiring admin privileges.
   - Resilience: handles non-ASCII paths and paths with spaces using explicit quotes.
3. **App Startup & CLI Flag (`Somning.App.Program`)**:
   - Checks `args`: if `--tray` or `--minimized` is present, suppresses any initial dialogs and runs directly in tray mode.
4. **Settings Dialog & ViewModel Integration (`SettingsViewModel` & `SettingsWindowManager`)**:
   - `SettingsViewModel`: add `StartWithWindows` property with two-way notification.
   - `SettingsWindowManager`: add pt-BR checkbox "Iniciar com o Windows".
   - When saved, syncs both `UserSettings.json` and registry key state.
