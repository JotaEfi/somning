Per D-07 and research Pattern 5:
- `KeyEvent` per `<interfaces>`.
- `KeyboardHook`: keeps the HOOKPROC delegate in a field (GC safety). `Start()` creates background thread "Somning.Hook" (AboveNormal) that calls SetWindowsHookEx(WH_KEYBOARD_LL, proc, null, 0), signals a ManualResetEventSlim when installed, then pumps GetMessage/TranslateMessage/DispatchMessage until WM_QUIT. `Dispose()` posts WM_QUIT via PostThreadMessage and joins with a 2 s timeout. Start() throws InvalidOperationException if the hook handle is invalid.
- `ChordTracker` (allocation-free helper used inside the callback): tracks Ctrl and Shift down state from hook events (left/right/generic VKs) because async state is stale inside the callback. When the space bar (virtual key 0x20) goes down while Ctrl and Shift are down: mark it owned, suppress (return 1), emit TriggerDown. While owned, further space-bar downs (auto-repeat) are suppressed and emitted as TriggerRepeat (activity signal for the amended D-08 watchdog; dropped silently if the channel is full). Space-bar up while owned → suppress, emit TriggerUp, clear owned (regardless of modifier state, so the user may release modifiers first). Ctrl/Shift events are never suppressed — this is what keeps their async state truthful for the watchdog.
- Callback rules: code < 0 → CallNextHookEx. Injected with dwExtraInfo == InputMarkers.Paste → CallNextHookEx without touching ChordTracker (D-09). Injected with InputMarkers.Test, non-injected, or other injected input → processed. Emit via a bounded Channel (capacity 64, FullMode DropWrite) `TryWrite` with Environment.TickCount64. No logging, locks, I/O or LINQ in the callback.
- `PhysicalKeyState.AreChordModifiersDown()` per `<interfaces>`. It reads only the two modifier keys; the suppressed trigger key's async state never changes while suppressed (plan-check probe), so it must not be consulted (amended D-08).
- Test helpers per `<interfaces>`. `KeyboardHookTests` ([Trait("Category","Desktop")], each test starts with Requires.Desktop(); release all injected keys in finally):
